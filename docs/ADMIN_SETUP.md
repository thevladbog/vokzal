# Безопасная настройка администратора

## Проблема

В первоначальной миграции был создан администратор с известным слабым паролем `admin123`, что представляет критическую угрозу безопасности.

## Решение

Администратор по умолчанию создается **неактивным** с placeholder-хэшем пароля. Для активации и установки надежного пароля используйте скрипт настройки.

## Использование скрипта setup-admin.sh

### Требования

- PostgreSQL клиент (`psql`)
- Docker (для генерации bcrypt хэша)
- Доступ к базе данных Вокзал.ТЕХ

### Запуск

```bash
./scripts/setup-admin.sh
```

Скрипт запросит:
1. Параметры подключения к БД (хост, порт, имя БД, пользователь, пароль)
2. Новый пароль администратора (с подтверждением)

### Требования к паролю

- ✅ Минимум 12 символов
- ✅ Заглавные буквы (A-Z)
- ✅ Строчные буквы (a-z)
- ✅ Цифры (0-9)
- ✅ Специальные символы (!@#$%^&*()_+=- и т.д.)

### Пример использования

```bash
$ ./scripts/setup-admin.sh

Вокзал.ТЕХ - Настройка администратора
===================================

Введите хост базы данных (по умолчанию: localhost):

5432
Введите имя базы данных (по умолчанию: vokzal):

Введите пользователя базы данных (по умолчанию: postgres):
postgres

===================================

Требования к паролю:
- Минимум 12 символов
- Содержит заглавные и строчные буквы
- Содержит цифры
- Содержит специальные символы
```

## Альтернативный способ (вручную)

Если у вас нет Docker или вы хотите настроить вручную:

### 1. Сгенерируйте bcrypt хэш

Используйте любой bcrypt генератор (онлайн или локальный):

```bash
# С помощью Go
go install golang.org/x/crypto/bcrypt/cmd/bcrypt@latest
echo -n 'ваш_надежный_пароль' | bcrypt

# С помощью Python
python3 -c "import bcrypt; print(bcrypt.hashpw(b'ваш_надежный_пароль', bcrypt.gensalt()).decode())"

# С помощью Node.js
npm install -g bcrypt
node -e "const bcrypt = require('bcrypt'); bcrypt.hash('ваш_надежный_пароль', 10, (err, hash) => console.log(hash));"
```

### 2. Обновите администратора в БД

```sql
UPDATE users 
SET password_hash = '$2a$10$ваш_сгенерированный_хэш', 
    is_active = true,
    updated_at = NOW()
WHERE id = '00000000-0000-0000-0000-000000000001';
```

## Рекомендации по безопасности

1. **Никогда не используйте слабые пароли** типа `admin123`, `password`, `12345678`
2. **Используйте уникальный пароль** для каждого окружения (dev, staging, production)
3. **Храните пароли в секретных хранилищах** (Vault, AWS Secrets Manager, Azure Key Vault)
4. **Регулярно меняйте пароли** администратора
5. **Включите двухфакторную аутентификацию** (планируется в будущих версиях)
6. **Логируйте все действия** администратора через audit сервис

## Проверка после настройки

1. Перейдите на http://localhost:3001
2. Войдите с логином `admin` и установленным паролем
3. Убедитесь, что вход успешен
4. Проверьте логи audit сервиса:

```bash
docker logs vokzal-audit
```

## Troubleshooting

### Ошибка: "command not found: psql"

Установите PostgreSQL клиент:

```bash
# macOS
brew install postgresql

# Ubuntu/Debian
sudo apt-get install postgresql-client

# CentOS/RHEL
sudo yum install postgresql
```

### Ошибка: "Could not connect to database"

Проверьте:
1. Запущен ли контейнер PostgreSQL: `docker ps | grep postgres`
2. Правильность параметров подключения
3. Firewall не блокирует порт 5432

### Ошибка: "Failed to generate password hash"

Убедитесь, что Docker запущен:

```bash
docker ps
```

Или используйте альтернативный способ генерации хэша (см. выше).

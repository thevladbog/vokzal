🎯 Введение ​

Руководство предназначено для администраторов системы Вокзал.ТЕХ. Админ-панель позволяет настраивать справочники, управлять пользователями, просматривать отчёты и мониторить работу сервисов.

Что вы можете делать ​

  • ✅ Управлять пользователями (создание, редактирование, роли, станции)
  • ✅ Настраивать станции (автовокзалы)
  • ✅ Создавать и редактировать маршруты
  • ✅ Просматривать и настраивать расписания
  • ✅ Просматривать рейсы по датам
  • ✅ Просматривать журнал аудита (152-ФЗ)
  • ✅ Открывать отчёты и дашборды мониторинга

🔐 Вход в систему ​

  1. Откройте админ-панель в браузере: admin.vokzal.tech (или адрес, выданный вашей организацией).
  2. Введите логин и пароль администратора.
  3. Нажмите Войти.

⚠️ Важно: Используйте надёжный пароль и не передавайте учётные данные третьим лицам.

🏠 Главный экран (Dashboard) ​

После входа отображается главная страница с приветствием и краткой статистикой (рейсы, билеты, выручка, заполняемость). С главной страницы доступны ссылки на разделы:

  • Расписания — управление расписаниями рейсов.
  • Станции — справочник автовокзалов.
  • Маршруты — справочник маршрутов.
  • Рейсы — просмотр рейсов по дате.
  • Отчёты — переход к отчётам и бизнес-метрикам.
  • Мониторинг — состояние сервисов и БД.
  • Пользователи (только для роли admin) — управление учётными записями.
  • Журнал аудита (только для admin) — просмотр логов операций (152-ФЗ).

👥 Управление пользователями ​

Доступно только пользователям с ролью admin.

Список пользователей ​

  1. Перейдите в раздел Пользователи.
  2. При необходимости отфильтруйте список по роли (администратор, диспетчер, кассир, контролёр).
  3. Для перехода по страницам используйте кнопки Назад / Вперёд.

Добавление пользователя ​

  1. Нажмите Добавить пользователя.
  2. Заполните поля:
    • Логин — уникальное имя для входа (от 3 до 50 символов).
    • Пароль — не менее 8 символов.
    • ФИО — полное имя.
    • Роль — администратор, диспетчер, кассир или контролёр.
    • Станция (опционально) — привязка к станции для кассиров/контролёров.
  3. Нажмите Создать.

Редактирование пользователя ​

  1. В списке пользователей нажмите иконку Редактировать у нужной строки.
  2. Измените ФИО, роль, пароль (при необходимости), статус (Активен/Неактивен).
  3. Нажмите Сохранить.

Удаление пользователя ​

  1. Нажмите иконку Удалить у нужной строки.
  2. Подтвердите удаление в диалоге.

⚠️ Важно: Удалённого пользователя нельзя восстановить. Деактивируйте учётную запись (снять «Активен»), если доступ нужно временно отключить.

🏢 Управление станциями ​

Раздел Станции предназначен для ведения справочника автовокзалов.

Просмотр и фильтр ​

  • Список станций отображается в таблице (код, название, адрес, часовой пояс).
  • В фильтре Город / название можно ввести часть названия или адреса для поиска.

Добавление станции ​

  1. Нажмите Добавить станцию.
  2. Заполните Название, Код (уникальный, до 10 символов), Адрес, Часовой пояс (по умолчанию Europe/Moscow).
  3. Нажмите Создать.

Редактирование и удаление ​

  • Редактировать — иконка карандаша у строки; можно изменить название, адрес, часовой пояс (код при редактировании не меняется).
  • Удалить — иконка корзины; подтвердите удаление в диалоге.

🛤 Управление маршрутами ​

В разделе Маршруты создаются и редактируются маршруты между станциями.

Список маршрутов ​

В таблице отображаются: название, расстояние (км), время в пути (мин), количество остановок, статус (активен/неактивен).

Создание маршрута ​

  1. Нажмите Добавить маршрут.
  2. Укажите Название, Расстояние (км), Время в пути (мин).
  3. Выберите первую остановку (станцию) из списка — обязательное поле для создания.
  4. Нажмите Создать.

Дополнительные остановки можно настроить при последующем редактировании (при наличии такой возможности в системе).

Редактирование маршрута ​

  1. Нажмите иконку Редактировать у маршрута.
  2. Измените название, расстояние, время в пути, статус Активен.
  3. Нажмите Сохранить.

📅 Расписания ​

Раздел Расписания показывает расписания рейсов по маршрутам: маршрут, время отправления, дни недели, цена, статус. Здесь можно создавать и редактировать расписания (кнопка Создать расписание и действия в таблице — в соответствии с реализованным в интерфейсе функционалом).

🚌 Рейсы ​

В разделе Рейсы отображаются рейсы на выбранную дату.

  1. Выберите дату в фильтре.
  2. В таблице отображаются: дата/время, маршрут (или идентификатор расписания), статус (запланирован, задержан, отменён, отправлен, прибыл), задержка (мин), перрон.

Используйте эту страницу для контроля рейсов на день и при необходимости согласования изменений с диспетчерской службой.

📋 Журнал аудита ​

Доступен только пользователям с ролью admin. Соответствует требованиям 152-ФЗ к учёту операций с персональными данными.

  1. Перейдите в раздел Журнал аудита.
  2. По умолчанию отображаются последние записи (лимит 100).
  3. Для фильтрации укажите:
    • С и По — период дат;
    • Тип сущности и ID сущности — операции по конкретной сущности (например, ticket);
    • ID пользователя — операции конкретного пользователя.
  4. Нажмите Применить фильтры для обновления списка.

В таблице отображаются: время, действие, тип сущности, ID сущности, ID пользователя.

📊 Отчёты и мониторинг ​

Отчёты ​

Раздел Отчёты содержит ссылку на дашборд Бизнес-метрики в Grafana (продажи, возвраты, фискализация). Открывайте отчёты по мере необходимости для анализа работы вокзала.

Мониторинг ​

Раздел Мониторинг содержит ссылки на дашборды Grafana:

  • Обзор сервисов — состояние микросервисов.
  • Мониторинг БД — состояние баз данных.

Используйте мониторинг для контроля доступности системы и оперативного реагирования на сбои.

❓ Частые вопросы ​

Как восстановить доступ пользователю после блокировки? ​

Откройте Пользователи, найдите пользователя, нажмите Редактировать и включите галочку Активен, затем сохраните.

Где посмотреть, кто и когда изменил данные? ​

В разделе Журнал аудита задайте фильтр по типу сущности и ID или по ID пользователя и периоду.

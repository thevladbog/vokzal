🎯 Рекомендации ​

Для запуска инфраструктуры ​

bash
# В корне проекта
make dev-up

# Или напрямую
cd infra/docker
docker-compose up -d

Для запуска Admin Panel ​

bash
cd ui/admin-panel
npm install
npm run dev
# Откроется на http://localhost:3001

Для запуска сервисов локально ​

bash
# Auth service
cd services/auth
go run cmd/main.go

# Schedule service
cd services/schedule
go run cmd/main.go

# ... аналогично для остальных сервисов

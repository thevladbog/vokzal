📄 Вокзал.ТЕХ — Регистрация ПО в Роспатенте ​

🎯 Цель ​

Официальная регистрация программы для ЭВМ под именем «Вокзал.ТЕХ — система управления автовокзалами» в Федеральной службе по интеллектуальной собственности (Роспатент).

📌 Официальное название ​

  • Полное: Программа для ЭВМ «Вокзал.ТЕХ — система управления автовокзалами»
  • Сокращённое: Вокзал.ТЕХ
  • Язык: Русский (в соответствии с ФЗ-129)

🧩 Описание программы ​

Назначение:
Автоматизация деятельности автовокзалов: ведение расписания, продажа билетов, посадка пассажиров, управление табло, документооборот.

Функции:

  • Учёт маршрутов, рейсов, автобусов, водителей
  • Продажа и возврат билетов
  • Работа с ККТ (АТОЛ)
  • Управление табло (общее и перронное)
  • Генерация посадочных ведомостей и отчётов
  • Интеграция с внешними сервисами (Yandex Maps, СБП, Telegram)

Технологии:

  • Язык программирования: Go, JavaScript (React)
  • ОС: Windows, Linux
  • База данных: PostgreSQL

📝 Рекомендации ​

  1. Используйте только русское название — "Вокзал.ТЕХ", без "Deparq" или "Vokzal Tech".

  3. Подчеркните уникальность: мульти-теннантность, интеграция с ККТ, голосовое оповещение.
  4. Приложите скриншоты интерфейса (опционально, но рекомендуется).

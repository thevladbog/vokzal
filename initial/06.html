🚀 Вокзал.ТЕХ — Руководство по развёртыванию ​

📦 Структура репозиториев ​

github.com/vokzal-tech/ ├── core-auth # auth-service (Go) ├── core-schedule # schedule-service (Go) ├── core-ticket # ticket-service (Go) ├── agent-fiscal # локальный агент (Go) ├── ui-admin # админ-панель (React) ├── ui-pos # POS (Tauri) ├── ui-board # табло (React) ├── ui-controller # интерфейс контролёра ├── docs # документация └── infra # Terraform, Kubernetes манифесты ​

🐳 Подготовка (локально) ​

Требования ​

  • Docker 24+
  • Docker Compose
  • Go 1.22+
  • Node.js 18+
  • PostgreSQL 15+, Redis 7+

Запуск окружения ​

bash
# Клонируем репозитории
git clone https://github.com/vokzal-tech/infra
cd infra/local
docker-compose up -d
Запустятся:
PostgreSQL (порт 5432)
Redis (порт 6379)
Traefik (порт 80, 443)
MinIO (порт 9000) — для документов
🏗️ Сборка сервисовПример: сборка auth-servicegit clone https://github.com/vokzal-tech/core-auth
cd core-auth
go build -o auth-service main.go
Или через Docker:docker build -t vokzal/auth:latest .
☸️ Kubernetes (production)Архитектура
Ingress: Traefik — маршрутизация по поддоменам
Namespaces:

vokzal-core
vokzal-ui
vokzal-agent


Secrets: API-ключи, сертификаты ККТ
PersistentVolume: БД, документы
Пример деплоя ticket-serviceapiVersion: apps/v1
kind: Deployment
metadata:
  name: ticket-service
  namespace: vokzal-core
spec:
  replicas: 2
  selector:
    matchLabels:
      app: ticket-service
  template:
    metadata:
      labels:
        app: ticket-service
    spec:
      containers:
        - name: ticket-service
          image: vokzal/ticket:latest
          ports:
            - containerPort: 8080
          env:
            - name: DB_URL
              valueFrom:
                secretKeyRef:
                  name: db-creds
                  key: url
🌐 Настройка доменаvokzal.tech        → Ingress (Kubernetes)
*.vokzal.tech      → Ingress (wildcard SSL)
api.vokzal.tech    → API Gateway
admin.vokzal.tech  → админ-панель
pos.vokzal.tech    → Tauri-приложение (для обновлений)
board.vokzal.tech  → табло
SSL — автоматически через Let's Encrypt (Traefik).🔐 Настройка безопасности
NetworkPolicy: ограничить межсервисный трафик.
RBAC: роли в Kubernetes.
Secrets: не хранить в коде.
Аудит: логировать все входы и операции.

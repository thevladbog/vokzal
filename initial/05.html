🔄 Вокзал.ТЕХ — API ​

🌐 Базовый URL ​

https://api.vokzal.tech/v1 Все микросервисы доступны через API Gateway с префиксом /v1.
Аутентификация: JWT Bearer Token.

🔐 Аутентификация ​

POST /auth/login ​

Аутентификация пользователя.

Запрос:

json
{
  "username": "kassir1",
  "password": "secret",
  "station_id": "rostov"
}
Ответ:{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.xxxxx",
  "user": {
    "id": "u123",
    "role": "cashier",
    "station_id": "rostov",
    "full_name": "Иван Кассиров"
  }
}

🎫 Продажа билетовPOST /tickets/sellПродажа билета.Запрос:{
  "trip_id": "t1",
  "seat_id": "s5",        // null — если без выбора места
  "passenger_name": "Анна Смирнова",  // null — если анонимный
  "passport": "4500 123456",
  "payment_method": "card"
}
Ответ:{
  "ticket_id": "tk123",
  "qr_code": "https://vokzal.tech/t/tk123",
  "price": 1500.00,
  "fiscal_receipt_url": "https://ofd.atol.ru/receipt/123"
}
POST /tickets/returnВозврат билета.Запрос:{
  "ticket_id": "tk123",
  "reason": "Не приехал"
}
Ответ:{
  "success": true,
  "refunded_amount": 1350.00,
  "penalty": 150.00,
  "fiscal_receipt_url": "https://ofd.atol.ru/receipt/124"
}
📋 ПосадкаPOST /boarding/startНачать посадку на рейс.Запрос:{
  "trip_id": "t1"
}
Ответ:{
  "success": true,
  "message": "Возвраты заблокированы для рейса t1"
}
POST /boarding/markОтметить посадку.Запрос:{
  "ticket_id": "tk123",
  "confirmed": true
}
Ответ:{
  "success": true
}
📢 Табло и оповещениеGET /board/publicДанные для общего табло.Ответ:{
  "departures": [
    {
      "trip_id": "t1",
      "route": "Ростов → Казань",
      "departure_time": "08:00",
      "platform": "Перрон 3",
      "status": "Задерживается на 15 мин"
    }

}
POST /announcementsДобавить голосовое оповещение.Запрос:{
  "text": "Рейс в Казань задерживается на 15 минут. Посадка начнётся у перрона 3.",
  "priority": "high"
}
Ответ:{
  "announcement_id": "a1",
  "status": "queued"
}
📄 ДокументыGET /documents/pd2?trip_id=t1Сгенерировать посадочную ведомость (ПД-2).Ответ:
PDF-файл с заполненной формой.POST /documents/customСгенерировать документ по шаблону.Запрос:{

  }

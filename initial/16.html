🛠️ Вокзал.ТЕХ — Руководство по интеграции с оборудованием ​

📌 Цель ​

Обеспечить стабильную работу системы с периферийными устройствами:

  • ККТ (АТОЛ)
  • Принтеры билетов
  • Сканеры штрих-кодов
  • Аудиосистема (голосовое оповещение)

🧰 Локальный агент (Go) ​

Назначение ​

  • Промежуточный слой между POS (Tauri) и оборудованием.
  • Запускается как служба: systemd (Linux) / Windows Service.
  • Слушает HTTP на порту 8081.

Установка ​

bash
# Linux
wget https://agent.vokzal.tech/v1/agent-linux-amd64.tar.gz
tar -xzf agent-linux-amd64.tar.gz
sudo cp vokzal-agent /usr/local/bin/
sudo cp vokzal-agent.service /etc/systemd/system/
sudo systemctl enable vokzal-agent
sudo systemctl start vokzal-agent
:: Windows
:: Скачать vokzal-agent.exe
:: Открыть PowerShell от имени администратора:
New-Service -Name "VokzalAgent" -BinaryPathName "C:\vokzal\agent\vokzal-agent.exe"
Start-Service VokzalAgent

📱 Сканер штрих-кодовТребования
Режим HID (как клавиатура)
Поддержка Code128, QR
Использование
При посадке: сканирование ШК на билете → автоматический ввод в систему.
Агент перехватывает ввод и передаёт в ticket.vokzal.tech.
🔊 Аудиосистема (TTS)Настройка
Агент получает текст оповещения от board.vokzal.tech.
Использует локальный TTS-движок (например, espeak или RHVoice).
Воспроизводит через аудиовыход ПК.
ПримерPOST /tts/speak
Content-Type: application/json

{
  "text": "Рейс в Казань задерживается на 15 минут. Посадка начнётся у перрона 3.",
  "voice": "aleksandr",
  "volume": 80
}

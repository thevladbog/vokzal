🌐 Вокзал.ТЕХ — Руководство по настройке многоязычности (RU/EN) ​

🎯 Цель ​

Обеспечить поддержку двух языков:

  • Русский (ru) — основной
  • Английский (en) — для международных пассажиров и интерфейсов

Система должна корректно отображать:

  • Интерфейс (POS, админка, табло)
  • Документы (билеты, ведомости)
  • Оповещения (голос, текст)

🧩 Подход к локализации ​

1. Формат: JSON-словари ​

Языковые ресурсы хранятся в формате: public/locales/ ├── ru/ │ ├── common.json │ ├── pos.json │ ├── boarding.json │ └── errors.json └── en/ ├── common.json ├── pos.json ├── boarding.json └── errors.json Пример common.json:

json
{
  "app.title": "Вокзал.ТЕХ",
  "button.sell": "Продать билет",
  "button.return": "Вернуть",
  "status.delayed": "Задерживается",
  "station": "Вокзал"
}
Английская версия:{
  "app.title": "Vokzal.TECH",
  "button.sell": "Sell ticket",
  "button.return": "Return",
  "status.delayed": "Delayed",
  "station": "Station"
}
2. Автоматическое определение языка
POS, админка: Язык выбирается при входе.
Табло: Язык задаётся в настройках перрона (например, "Перрон 1 — RU", "Международный зал — RU+EN").
API: Язык передаётся в заголовке:
Accept-Language: ru-RU, en-US;q=0.8


3. Реализация в React (i18next)Установкаnpm install i18next react-i18next i18next-browser-languagedetector i18next-http-backend
Инициализация// i18n.js
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import LanguageDetector from 'i18next-browser-languagedetector';
import HttpApi from 'i18next-http-backend';

i18n
  .use(HttpApi)
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    supportedLngs: ['ru', 'en'],
    fallbackLng: 'ru',
    detection: {
      order: ['cookie', 'localStorage', 'navigator'],
      caches: ['cookie']
    },
    backend: {
      loadPath: '/locales/{{lng}}/{{ns}}.json'
    },
    react: {
      useSuspense: false
    }
  });

export default i18n;
Использование в компонентеimport { useTranslation } from 'react-i18next';

function TicketForm() {
  const { t } = useTranslation();
  return (
    <button>{t('button.sell')}</button>
  );
}
4. Локализация документовБилеты
Генерируются с учётом языка пассажира (если указан).
Пример:
Направление: Ростов → Казань
Direction: Rostov → Kazan


Посадочные ведомости (ПД-2)
Основной язык — русский (по ГОСТ).
Дополнительная колонка: Passenger Name (EN).
5. Голосовое оповещение (TTS)Поддержка языков:
Русский: Голос "Алёна" (RHVoice)
Английский: Голос "David" (espeak)
Логика:
Если в очереди оповещений есть английский текст → воспроизводится на английском.
Если рейс международный → дублирование: сначала русский, потом английский.
Пример:
"Рейс в Казань задерживается на 15 минут. Посадка у перрона 3."
"Flight to Kazan is delayed by 15 minutes. Boarding at platform 3."

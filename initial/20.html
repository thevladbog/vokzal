🔄 Стратегия резервного копирования ​

1. Полное резервное копирование ​

  • Раз в сутки (в 02:00)
  • Всё: БД, документы, логи
  • Шифрование: gpg --encrypt

2. Инкрементное резервное копирование ​

  • Каждые 4 часа
  • Только изменения
  • Использует rsync и WAL-G для PostgreSQL

3. Хранение ​

  • Основное: MinIO (локально)
  • Резервное: Внешнее S3-хранилище (например, Selectel)
  • Срок хранения: 365 дней

🧰 Инструменты ​

  • WAL-G — для PostgreSQL
  • Restic — для общего бэкапа
  • MinIO — локальное хранилище
  • BorgBackup — опционально, для шифрования

🔄 Восстановление ​

1. Восстановление PostgreSQL ​

bash
# Скачать последний бэкап
wget https://backup.vokzal.tech/db/latest.dump.gpg
gpg --decrypt latest.dump.gpg | pg_restore -U vokzal -d vokzal_db
2. Восстановление документовrsync -av backup.vokzal.tech:/documents/ /var/vokzal/documents/
3. Восстановление конфигурацийgit clone https://github.com/vokzal-tech/infra-config
kubectl apply -f .

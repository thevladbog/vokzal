🧱 Вокзал.ТЕХ — Модель данных ​

📂 Основные сущности ​

1. Station (Автовокзал) ​

sql
station_id      UUID (PK)
name            VARCHAR(100)    -- "Ростов-на-Дону Центральный"
code            VARCHAR(10)     -- "ROSTOV"
address         TEXT
timezone        VARCHAR(50)     -- "Europe/Moscow"
created_at      TIMESTAMP
updated_at      TIMESTAMP
2. Bus (Автобус)bus_id          UUID (PK)
plate_number    VARCHAR(12)     -- "А123БВ 777"
model           VARCHAR(50)     -- "МАЗ 251"
capacity        INT             -- 45
status          ENUM('active', 'maintenance', 'out_of_service')
station_id      UUID (FK)       -- базовый вокзал
created_at      TIMESTAMP
updated_at      TIMESTAMP
3. Driver (Водитель)driver_id       UUID (PK)
full_name       VARCHAR(100)
license_number  VARCHAR(20)
experience_years INT
phone           VARCHAR(15)
station_id      UUID (FK)
created_at      TIMESTAMP
updated_at      TIMESTAMP
4. Route (Маршрут)route_id        UUID (PK)
name            VARCHAR(100)    -- "Ростов → Казань"
stops           JSONB           -- [{ station_id, order, arrival_offset_min }]
distance_km     DECIMAL(8,2)
duration_min    INT
is_active       BOOLEAN
created_at      TIMESTAMP
updated_at      TIMESTAMP
5. Schedule (Расписание)schedule_id     UUID (PK)
route_id        UUID (FK)
departure_time  TIME
days_of_week    JSONB           -- [1, 3, 5] — пн, ср, пт
platform        VARCHAR(10)     -- "Перрон 3"
is_active       BOOLEAN
created_at      TIMESTAMP
updated_at      TIMESTAMP
6. Trip (Рейс — экземпляр расписания)trip_id         UUID (PK)
schedule_id     UUID (FK)
date            DATE
status          ENUM('scheduled', 'delayed', 'cancelled', 'departed', 'arrived')
delay_minutes   INT
platform        VARCHAR(10)
departure_actual TIMESTAMP
arrival_actual  TIMESTAMP
bus_id          UUID (FK)
driver_id       UUID (FK)
created_at      TIMESTAMP
updated_at      TIMESTAMP
7. Seat (Место)seat_id         UUID (PK)
bus_id          UUID (FK)
number          INT             -- 1–45
type            ENUM('regular', 'vip', 'disabled', 'near_exit')
is_available    BOOLEAN
created_at      TIMESTAMP
updated_at      TIMESTAMP
8. Ticket (Билет)ticket_id       UUID (PK)
trip_id         UUID (FK)
seat_id         UUID (FK)       -- NULL, если без выбора места
passenger_name  VARCHAR(100)    -- NULL, если анонимный
passport        VARCHAR(20)     -- при необходимости
price           DECIMAL(10,2)
status          ENUM('active', 'returned', 'used')
return_penalty  DECIMAL(10,2)   -- штраф при возврате
sold_at         TIMESTAMP
sold_by         UUID (FK → User)
station_id      UUID (FK)
created_at      TIMESTAMP
updated_at      TIMESTAMP
9. BlockingRule (Правило блокировки мест)rule_id         UUID (PK)
station_id      UUID (FK)
route_id        UUID (FK)
seat_range      VARCHAR(20)     -- "40-45"
reason          ENUM('station_lock', 'privileged', 'maintenance')
valid_from      DATE
valid_to        DATE
created_at      TIMESTAMP
updated_at      TIMESTAMP
10. DocumentTemplate (Шаблон документа)template_id     UUID (PK)
name            VARCHAR(100)    -- "Посадочная ведомость (ПД-2)"
content         TEXT            -- HTML с плейсхолдерами: {{trip_id}}, {{passengers}}
format          ENUM('pdf', 'docx')
is_default      BOOLEAN
created_at      TIMESTAMP
updated_at      TIMESTAMP
🔄 Связи
Station → Bus, Driver, Trip, Ticket, BlockingRule
Route → Schedule → Trip
Trip → Ticket, Seat (через ticket.seat_id)
User (кассир, диспетчер) → Ticket.sold_by, AuditLog.user_id
📊 Индексы (ключевые)
ticket(trip_id, seat_id) — для проверки занятости
trip(schedule_id, date) — для расписания
audit_log(entity_type, entity_id) — для аудита
blocking_rule(route_id, station_id) — для проверки блокировок

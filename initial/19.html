🎯 Цель ​

Обеспечить:

  • Непрерывный контроль работоспособности системы
  • Быстрое выявление и устранение инцидентов
  • Соответствие требованиям 152-ФЗ и 54-ФЗ

📈 Ключевые метрики ​

1. Системные метрики ​

  • CPU, RAM, Disk Usage (на всех нодах)
  • Сетевая нагрузка
  • Задержки между микросервисами

2. Бизнес-метрики ​

  • Количество продаж в час
  • Среднее время продажи билета
  • Число возвратов
  • Загрузка автобусов (%)
  • Количество активных касс

3. Инфраструктурные метрики ​

  • Доступность API (http_requests_total, http_request_duration_seconds)
  • Состояние БД (подключения, медленные запросы)
  • Статус ККТ (онлайн/оффлайн)
  • Очереди NATS (длина, задержки)

📋 Дашборды в Grafana ​

1. Операционный дашборд ​

  • Состояние всех микросервисов
  • Загрузка CPU/памяти
  • Количество запросов в секунду
  • Ошибки 5xx, 4xx

2. Бизнес-дашборд ​

  • Продажи по вокзалам
  • Самые популярные направления
  • Доходы по часам
  • Возвраты с штрафами

3. ККТ и фискализация ​

  • Количество чеков (приход/возврат)
  • Статус Z-отчётов
  • Ошибки печати

📦 Логирование ​

1. Уровни логов ​

  • DEBUG — отладка (только в dev)
  • INFO — операции (продажа, возврат, посадка)
  • WARN — предупреждения (ККТ медленно отвечает)
  • ERROR — сбои (ошибка оплаты, потеря связи)

2. Формат логов (JSON) ​

json

  "timestamp": "2025-04-10T08:15:23Z",

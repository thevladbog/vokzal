API Documentation ​

Полная OpenAPI спецификация всех микросервисов:

  • Auth Service - Аутентификация и авторизация
  • Schedule Service - Управление расписанием
  • Ticket Service - Управление билетами
  • Интеграционное API для всех сервисов

Архитектура системы ​

  • Общая архитектура платформы
  • Микросервисная структура
  • Схемы баз данных
  • Диаграммы потоков данных

Руководство кассира ​

Полное руководство для работников касс:

  • Продажа билетов
  • Возврат билетов
  • Работа с оплатой
  • Закрытие смены
  • Решение проблем

Руководство для пассажиров ​

Как купить билет онлайн:

  • Поиск и выбор рейса
  • Оплата билета
  • Получение электронного билета
  • Возврат билета
  • Частые вопросы

Руководство администратора ​

Для администраторов системы:

  • Управление пользователями
  • Настройка расписания
  • Управление маршрутами
  • Создание отчётов
  • Мониторинг системы

Руководство диспетчера ​

Для диспетчеров:

  • Планирование рейсов
  • Назначение автобусов и водителей
  • Мониторинг рейсов
  • Управление перронами

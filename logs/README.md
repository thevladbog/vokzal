# Логи микросервисов Вокзал.ТЕХ

Эта папка содержит логи всех запущенных микросервисов.

## Структура

- `*.log` — логи каждого микросервиса (auth.log, schedule.log, и т.д.)
- `.pids/` — PID файлы для управления процессами

## Команды

```bash
# Просмотр логов в реальном времени
tail -f logs/auth.log

# Просмотр последних 100 строк
tail -100 logs/schedule.log

# Поиск ошибок
grep ERROR logs/*.log

# Очистка логов
rm logs/*.log
```

## Примечание

Папка `logs/` находится в `.gitignore` и не коммитится в репозиторий.

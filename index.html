🎯 О проекте ​

Вокзал.ТЕХ — современная open-source платформа для автоматизации работы автовокзалов.

Основные возможности: ​

  • ✅ Продажа билетов (касса + онлайн)
  • ✅ Управление расписанием и рейсами
  • ✅ Интеграция с платёжными системами
  • ✅ Фискализация (54-ФЗ)
  • ✅ Защита персональных данных (152-ФЗ)
  • ✅ Табло отправлений
  • ✅ Мобильное приложение для пассажиров
  • ✅ Отчётность и аналитика

Технологии: ​

  • Backend: Go (микросервисы)
  • Frontend: React + TypeScript
  • БД: PostgreSQL
  • Message Broker: NATS
  • Мониторинг: Prometheus + Grafana

🚀 Быстрый старт ​

bash
# Клонирование репозитория
git clone https://github.com/vokzal-tech/vokzal.git
cd vokzal

# Запуск инфраструктуры
make infra-up

# Применение миграций
make migrate-up

# Запуск всех сервисов
make services-up
